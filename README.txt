ClipNest v1.5.0

التحديث:
- استبدال تبويب المفضلة بتبويب طلباتي.
- نقل المفضلة إلى فلتر أعلى صفحة المحفوظات.
- إضافة مدير طلبات كامل: المتجر، تواريخ الوصول، حالة الطلب، رقم الطلب والتتبع، الرابط، السعر والملاحظات.
- زر تم الاستلام ينقل الطلب للسجل دون حذفه.
- ترتيب الطلبات النشطة حسب أقرب موعد وصول متوقع.
- إحصاءات: قيد الانتظار / تصل قريبًا / تم الاستلام.
- إضافة رابط محفوظ مباشرة إلى طلباتي.
- النسخة الاحتياطية تشمل الطلبات.

ارفع جميع الملفات إلى نفس المجلد في GitHub Pages أو Cloudflare Pages.
