ClipNest v1.3.0

التحديثات:
- إعادة تصميم الواجهة بالكامل وفق التصميم المعتمد.
- أيقونة كاملة تقريبًا بدون الحواف الفارغة السابقة.
- شريط تنقل سفلي مضغوط لإزالة الفراغ الكبير أسفل التطبيق.
- تصنيفات متعددة المستويات.
- إضافة تنظيم افتراضي: أكل > مطاعم/كوفيات > أبوظبي/دبي/الشارقة.
- بحث شامل وفلترة حسب نوع المحتوى.
- عرض قائمة أو شبكة.
- حفظ محلي فوري عبر IndexedDB والعمل دون إنترنت بعد التثبيت.
- رقم الإصدار ظاهر في نهاية الإعدادات.

ارفع جميع الملفات معًا إلى GitHub Pages أو Cloudflare Pages عبر HTTPS.
