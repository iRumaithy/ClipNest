ClipNest PWA v1.4.0

أهم تحديثات هذه النسخة:
- إعادة تجهيز الأيقونة لتملأ مساحة أيقونة iOS بشكل أفضل دون فراغ داخلي كبير.
- نظام تصنيف جديد بثلاث خانات مستقلة: تصنيف أساسي + تصنيف ثانوي + مدينة.
- التصنيف الثانوي يتغير حسب التصنيف الأساسي ويمكن إضافة خيار يدوي ويحفظ للمرات القادمة.
- المدن الافتراضية: أبوظبي، دبي، الشارقة، عجمان، أم القيوين، رأس الخيمة، الفجيرة، العين.
- ترحيل تلقائي للمحفوظات القديمة من نظام التصنيفات الهرمي إلى النظام الجديد قدر الإمكان.
- البحث يشمل التصنيف الأساسي والثانوي والمدينة والوسوم.
- رقم الإصدار ظاهر في آخر الإعدادات.
